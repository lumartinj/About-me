# Logos

The SVGs in this folder are neutral placeholder tiles (monogram + short name).
To use official logos, drop the file in here with the **same file name**
(e.g. `airbus.svg`, `uc3m.svg`, or change the extension in `index.html` if you use PNG).

Use official brand-kit / press-kit versions and check each organisation's
logo-usage guidelines before publishing.
